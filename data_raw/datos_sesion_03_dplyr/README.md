# Datos para la sesión 3

`conteos_genes.csv` contiene conteos artificiales de diez genes en cuatro muestras. No proceden de un experimento ni permiten inferencias biológicas.

Colocar la carpeta `datos_sesion_03` dentro de `data_raw/` del proyecto RStudio, y renombrar la carpeta descomprimida a `datos_sesion_03` si fuera necesario.

Esta sesión también utiliza `resultados_blast.tsv` del paquete de la sesión 2, que debe estar en `data_raw/datos_sesion_02_blast/`.
