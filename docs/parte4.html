4  Estructuras de control

Hasta ahora hemos ejecutado instrucciones de R de manera secuencial. Sin embargo, con frecuencia necesitamos tomar decisiones según las características de nuestros datos o repetir operaciones sin escribir el mismo código varias veces. Para ello utilizamos las estructuras de control.

En esta sección estudiaremos dos grupos:

  • Condicionales: if, else if y else, que permiten ejecutar instrucciones dependiendo de una condición lógica.
  • Ciclos: for y while, que permiten repetir instrucciones. En for recorremos los elementos de una secuencia o colección; en while repetimos mientras una condición siga siendo verdadera.

4.1 Condicionales: if, else if y else

La instrucción if evalúa una condición cuyo resultado debe ser un único valor lógico: TRUE o FALSE. Si la condición es verdadera, ejecuta el bloque entre llaves; si es falsa, lo omite.

Código 
if (condicion) {
  # Instrucciones cuando la condición es TRUE
}

if (condicion) {
  # Instrucciones cuando la condición es TRUE
} else {
  # Instrucciones cuando la condición es FALSE
}

if (condicion_1) {
  # Primera alternativa
} else if (condicion_2) {
  # Segunda alternativa
} else {
  # Si ninguna condición anterior se cumple
}

Por ejemplo, podemos decidir si una secuencia de ADN cumple con una longitud mínima:

Código 
secuencia <- "ATGCGT"
longitud <- nchar(secuencia)

if (longitud >= 10) {
  print("La secuencia tiene al menos 10 nucleótidos")
}

Como longitud vale 6, no se imprime ningún mensaje. Si queremos contemplar ambos casos, utilizamos else:

Código 
if (longitud >= 10) {
  print("La secuencia tiene al menos 10 nucleótidos")
} else {
  print("La secuencia tiene menos de 10 nucleótidos")
}
[1] "La secuencia tiene menos de 10 nucleótidos"

Para distinguir más de dos situaciones, podemos incorporar else if:

Código 
if (longitud >= 20) {
  print("Secuencia larga")
} else if (longitud >= 10) {
  print("Secuencia mediana")
} else {
  print("Secuencia corta")
}
[1] "Secuencia corta"

R revisa las condiciones en orden y ejecuta únicamente el primer bloque cuya condición sea verdadera. Por ello, el orden de las comparaciones importa.

ImportanteCondiciones lógicas en R

La condición de if debe producir un solo TRUE o FALSE, y no debe ser NA. Para combinar condiciones escalares podemos utilizar && (y) y || (o). Si necesitamos evaluar una condición sobre cada elemento de un vector, veremos más adelante ifelse().

4.1.1 Validación de valores y condicionales anidados

En ocasiones necesitamos comprobar primero si un dato es válido y después clasificarlo. Por ejemplo:

Código 
valor <- -3

if (is.na(valor)) {
  print("El valor está ausente")
} else {
  if (valor < 0) {
    print("Es negativo")
  } else if (valor > 0) {
    print("Es positivo")
  } else {
    print("Es cero")
  }
}
[1] "Es negativo"

Este es un condicional anidado, porque contiene un if dentro de otro. En este caso también podemos escribir una versión sin anidamiento:

Código 
if (is.na(valor)) {
  print("El valor está ausente")
} else if (valor < 0) {
  print("Es negativo")
} else if (valor > 0) {
  print("Es positivo")
} else {
  print("Es cero")
}
[1] "Es negativo"

Ambas versiones producen el mismo resultado. La segunda suele ser más fácil de leer.

Advertencia🧠 Ejercicio 1. Clasificación de un valor

  • "Sin lecturas" si es cero.
  • "Con lecturas" si es positivo.

Prueba tu código con NA, -2, 0 y 15.

TipSolución
Código

  print("Dato faltante")

[1] "Con lecturas"

4.1.2 Condiciones sobre vectores: ifelse(), all(), any() y which()

La función ifelse() evalúa una condición elemento por elemento y devuelve un resultado de acuerdo con si cada elemento satisface la condición.

Código 
conteos <- c(0, 12, 4, 0, 25)

estado <- ifelse(conteos > 0, "Detectado", "No detectado")
estado
[1] "No detectado" "Detectado"    "Detectado"    "No detectado" "Detectado"

En cambio, all(), any() y which() resumen o localizan los resultados de comparaciones lógicas:

Código 
conteos <- c(0, 12, 4, 0, 25)

all(conteos >= 0)  # ¿Todos los conteos son no negativos?
[1] TRUE
Código 
any(conteos == 0)  # ¿Existe al menos un cero?
[1] TRUE
Código 
which(conteos == 0) # ¿En qué posiciones hay ceros?
[1] 1 4

Observa que all() y any() devuelven un único valor lógico, mientras que which() devuelve las posiciones de los elementos que cumplen la condición, no sus valores.

Nota¿Qué sucede con los valores faltantes?

Si el vector contiene NA, all() y any() pueden devolver NA cuando no sea posible determinar el resultado. En algunos casos se puede usar na.rm = TRUE, pero primero hay que decidir si tiene sentido ignorar los datos faltantes. which() no incluye posiciones cuyo resultado lógico sea NA.

Advertencia🧠 Ejercicio 2. Verificación de conteos

  3. Obtener las posiciones de los conteos iguales a cero.
  4. Crear un vector que indique "Presente" o "Ausente" según si el conteo es mayor que cero.
TipSolución

[1] TRUE

[1] 2 5

[1] "Presente" "Ausente"  "Presente" "Presente" "Ausente"  "Presente"

4.2 Ciclo for

Un ciclo for ejecuta un bloque de instrucciones una vez por cada elemento de una secuencia o colección. Es útil cuando conocemos qué elementos queremos recorrer, por ejemplo, los identificadores de varias muestras o las secuencias almacenadas en un vector.

Código 
for (elemento in coleccion) {
  # Instrucciones que se ejecutan para cada elemento
}

Un ejemplo sencillo consiste en recorrer los números del 1 al 5:

Código 
for (i in 1:5) {
  print(i)
}
[1] 1
[1] 2
[1] 3
[1] 4
[1] 5

La variable i toma sucesivamente los valores de la secuencia. Al terminar el ciclo, conserva el último valor asignado en el entorno actual, aunque no es recomendable depender de ese efecto para escribir otros cálculos.

4.2.1 Recorrer secuencias biológicas

Supongamos que tenemos varias secuencias y queremos conocer su longitud:

Código 
secuencias <- c("ATGC", "ATGCGT", "CCATGAA")

for (secuencia in secuencias) {
  print(nchar(secuencia))
}
[1] 4
[1] 6
[1] 7

Si queremos guardar las longitudes para utilizarlas posteriormente, conviene crear primero un vector con el tamaño adecuado:

Código 
longitudes <- numeric(length(secuencias))

for (i in seq_along(secuencias)) {
  longitudes[i] <- nchar(secuencias[i])
}

longitudes
[1] 4 6 7

Aquí seq_along(secuencias) genera las posiciones del vector. Es preferible a 1:length(secuencias) porque también funciona correctamente si el vector está vacío.

TipBuenas prácticas al usar ciclos

Cuando sabemos cuántos resultados vamos a guardar, es recomendable reservar el espacio antes de iniciar el ciclo, por ejemplo con numeric(), character() o vector("list", n). Así evitamos ampliar el objeto en cada iteración.

4.2.2 Combinar for e if

Podemos usar un condicional dentro de un ciclo para clasificar cada elemento:

Código 
secuencias <- c("ATGC", "ATGCGT", "CCATGAA")

for (secuencia in secuencias) {
  if (nchar(secuencia) >= 6) {
    print("Longitud de al menos 6 nucleótidos")
  } else {
    print("Longitud menor que 6 nucleótidos")
  }
}
[1] "Longitud menor que 6 nucleótidos"
[1] "Longitud de al menos 6 nucleótidos"
[1] "Longitud de al menos 6 nucleótidos"
Advertencia🧠 Ejercicio 3. Longitudes de secuencias

4.3 Ciclo while

A diferencia de for, un ciclo while repite un bloque de instrucciones mientras una condición sea verdadera. La condición se comprueba antes de cada iteración: si desde el inicio es FALSE, el bloque no se ejecuta ninguna vez.

Código 
while (condicion) {
  # Instrucciones que se repiten mientras la condición sea TRUE
}

Por ejemplo, podemos incrementar un contador hasta que alcance un valor determinado:

Código 
i <- 0

while (i < 5) {
  print(i)
  i <- i + 1
}
[1] 0
[1] 1
[1] 2
[1] 3
[1] 4
Código 
i
[1] 5

Se imprimen los valores de 0 a 4. Cuando i alcanza el valor 5, la condición i < 5 deja de cumplirse y termina el ciclo.

AdvertenciaEvitar ciclos infinitos

En un while debemos asegurarnos de que alguna instrucción pueda modificar la condición de salida. De lo contrario, el ciclo podría continuar indefinidamente. Por ejemplo, el siguiente código no debe ejecutarse:

Código 
i <- 0
while (i < 5) {
  print(i)
  # Falta incrementar i
}

4.3.1 Ejemplo: encontrar un umbral

Queremos encontrar el primer entero positivo cuyo cuadrado sea mayor que 50:

Código 
limite <- 50
numero <- 0

while (numero^2 <= limite) {
  numero <- numero + 1
}

numero
[1] 8
Código 
numero^2
[1] 64

El resultado es 8, porque 7^2 = 49 no supera el límite, pero 8^2 = 64 sí.

4.3.2 Ejemplo: recorrer progresivamente una secuencia

También podemos construir fragmentos crecientes de una secuencia:

Código 
secuencia <- "ATGCGT"
posicion <- 1
fragmentos <- character(nchar(secuencia))

while (posicion <= nchar(secuencia)) {
  fragmentos[posicion] <- substr(secuencia, 1, posicion)
  posicion <- posicion + 1
}

fragmentos
[1] "A"      "AT"     "ATG"    "ATGC"   "ATGCG"  "ATGCGT"

La función substr(secuencia, 1, posicion) extrae los caracteres comprendidos entre las posiciones indicadas.

Advertencia🧠 Ejercicio 4. Alcanzar una longitud

Imagina que estamos construyendo una secuencia mediante la adición de un nucleótido "A" en cada iteración. Escribe un ciclo while que comience con una cadena vacía y se detenga cuando la secuencia alcance 8 nucleótidos. Muestra el resultado final.

TipSolución
Código 
secuencia <- ""

while (nchar(secuencia) < 8) {
  secuencia <- paste0(secuencia, "A")
}

secuencia
[1] "AAAAAAAA"
Código 
nchar(secuencia)
[1] 8

4.4 ¿Cuándo utilizar cada estructura?

Estructura ¿Para qué sirve? Ejemplo de aplicación
if / else Elegir entre alternativas a partir de una condición única. Verificar si un conteo es válido.
ifelse() Clasificar elementos de un vector. Etiquetar conteos positivos y ceros.
for Recorrer una colección de elementos. Calcular la longitud de varias secuencias.
while Repetir hasta que deje de cumplirse una condición. Construir una secuencia hasta alcanzar una longitud.
NotaPara recordar

En R muchas operaciones sobre vectores pueden realizarse sin escribir ciclos explícitos. Por ejemplo, nchar(secuencias) calcula directamente la longitud de todas las secuencias de un vector. Aprender for y while sigue siendo importante para comprender el flujo de ejecución y resolver tareas más complejas; posteriormente veremos alternativas para trabajar con colecciones de datos.
